# References

Refs is our curated route to useful knowledge wherever it lives: source code,
upstream documentation, wikis, and skills. Keep material with its owner; make it
easy to find, cite, and use through Rekon.

Look first in `~/archive/<org>/<repo>` for upstream source and
`~/wiki/<org>/<repo>` for generated project wikis. Keep the canonical upstream
URL alongside local references so their origin stays clear.

- [Skills](/refs/skills.md) — how we select, compose, and maintain skills.
- [Core index](/refs/GLOBAL.md) — brief cues and direct links for global context.
- [Upstream reference mirrors](/upstream/README.md) — preserving a source
  baseline when maintaining our own adaptation.

The [constitution](/constitution/README.md#doc-constitution-references-links)
explains source ownership and meaningful references; refs puts those principles
to work with concrete sources.
