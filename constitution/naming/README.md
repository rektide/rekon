## Short codes in use

Use short names in conversation, headings, and tickets, and introduce them with
an ordinary link to their home. Each code is a self-describing file — workspace
codes under [`codes/`](/codes), agent codes as the definitions under
[`agents/`](/agents) — and the generated [codes glossary](/codes/GLOSSARY.md)
maps each code to its target as a `file#tag` string. Notes compose from
priority-ordered `points:` (or an agent's `note:`), so a row leads with its
core fact. Dormant agent definitions take a `.md.disabled` suffix: defined but
inert, neither loaded nor listed. This section keeps the recorded practice
without loading the entire exploration wave.

**October 22 ruling — single letters are guarded treasures.** `g` is reclaimed
for the GLM-max agent; the global-guidance umbrella is retired, not renamed —
its sub-things carry their own codes and take prefixes (selectively, per the
`rk` rule) when they need grouping. `t` becomes `rkt` (rk's tool); `p` becomes
`prax`. `con` keeps its own code as the broadest governing document; `cf`
stays, softened to "usually". The earlier October 6 correction (`g` global,
`p` praxis, `t` tool) stands as history above.

**Shortcodes are reference vocabulary, not directory names.** The human
explicitly corrected that conflation on October 6: `g` global, `p` praxis,
`t` tool. The chosen physical toolkit is one `tool/` tree with shared
domain-grouped implementation. Numeric clauses need their own stated meanings;
this table does not manufacture a `g0`/`p0`/`t0` numbering scheme.

The [earlier human ruling](/constitution/naming/exploration/proposal4.glm53m.md#the-override-stated-as-ruling)
explicitly restored glossary abbreviations and cross-modal aliases. Their use
does not await adoption of every later grammar proposal. Short codes identify
their concerns through declared context; ordinary links provide the actual
navigation today. There is no implied installed short-code resolver.

For a durable citation, include the exact path and useful anchor. For historical
evidence, include its revision. Keep an alias's owner explicit when crossing
from a document to a ticket, tool, actor, or source repository. Do not repurpose
an existing code for a different concern without recording the change.

The [recovered shortcode history](/design/rekon/shortcodes0.glm53m.md)
locates the September requests for glossary aliases and short-plus-elaborated
references. It also separates those earlier practices from the October `g` /
`p` / `t` direction. The practical gap was a maintained table and habitual use;
the earlier human ruling had already restored abbreviations.
